# formuly-ii

Скил для Claude Code и Codex: чистит русский текст, написанный с участием ИИ, от машинных формул и привычек мышления модели. Сравнивает текст с тем, как автор писал сам до ИИ, и правит только то, что ему чуждо.

Модель пишет по-русски узнаваемыми оборотами: «не X, а Y», «почти», «…, и это самый частый ход», «Отсюда самый неприятный вывод», «как мы видели в первой главе», «разбор и есть витрина», длинные фразы «вывод: пояснение». Читатель замечает такой почерк за абзац и перестаёт верить даже сильным местам. Если просто попросить модель «убрать следы ИИ», она оставит половину формул и подставит вместо убранных свои же: «Вот и ответ», «Значит,», «Так что…», тире.

## Откуда

Скил собран на правке книги Александра Дублина «Кому показать бизнес» (2026), написанной вместе с Claude. В книге внесено 613 правок по формулам: 229 по фигуре «не X, а Y» и 384 по подписям, слову «почти» и синтаксису. Мерилом служили посты автора за 2016–2022 годы, написанные до ИИ. Все примеры «было → стало» в каталоге взяты из этой правки.

| Оборот, на 10 тысяч слов | Книга до | После | Автор до ИИ |
|---|---:|---:|---:|
| хвост «…, и это …» | 8,6 | 0 | 0 |
| «как мы видели», «Отсюда», «Беда в том» | 7,6 | 0 | 0 |
| «ровно» в значении «именно» | 4,3 | 0,3 | 0,2 |
| оценочное «честно», «честный» | 7,6 | 1,8 | 1,4 |
| «почти» | 17,8 | 0 | 0,9 |
| фраз с точкой с запятой | 3,9 % | 1,6 % | 1,5 % |
| фраз с двоеточием | 29 % | 23,7 % | 18 % |

## Семь привычек, из которых растут формулы

| Привычка | Как выглядит |
|---|---|
| Спор с выдуманным собеседником | «не X, а Y», «Y, а не X», «Дело не в X. Дело в Y», «увереннее, не точнее» |
| Оценка вместо числа | «почти всегда», «почти никто», «единственный» без факта |
| Объявленный вывод | «и это важно», «самый неприятный вывод», «стоит заметить» |
| Связки, изображающие логику | «Отсюда…», «так что», «а значит», «как мы видели» |
| Подчёркнутая точность и искренность | «ровно», «и есть», «честно» |
| Две мысли в одной фразе | «вывод: пояснение», «…; …», хвост «…, и это …» |
| Драматическая пауза | «Беда в том, что…», «Ответ простой:», фраза-приговор в конце каждого раздела |

Чистить надо привычку. Если заменить одно слово другим, формула вернётся через абзац в новом обличье.

## Как проверяли скил

Тестовый фрагмент главы (275 слов) с 25 заложенными формулами, данными в таблице и ловушками: цитатой с «не X, а Y» внутри, двумя самостоятельными фактами через «а», «почти никто» без числа в данных. Задача агенту одна и та же: «Убери из текста следы ИИ-письма, голос сохрани, факты не меняй».

| | Без скила, 3 прогона | Со скилом, 3 прогона |
|---|---|---|
| Осталось формул из заложенных | 7, 10, 7 | 1, 1, 1 (законный случай: два факта через «а») |
| Вместо убранной формулы вписана новая | в двух прогонах из трёх | ни разу |
| «Почти» | оставлено во всех трёх | убрано везде; число взято из таблицы, где числа нет, задан вопрос автору |
| Цитата героя | не тронута | не тронута |

Первая версия скила дробила текст: средняя длина фразы падала с 11 до 8,5 слова. После правки рецепта («Ритм после правки») длина держится на 10,2–11,1 слова, формулы уходят так же. Ещё одна правка рецепта запретила при соединении фраз вставлять «потому что» и «ведь» там, где автор причину не называл; два контрольных прогона после неё прошли чисто.

## Что внутри

| Файл | Зачем |
|---|---|
| `SKILL.md` | порядок работы, рецепт правки по каждой формуле, что не трогать, частые ошибки |
| `references/spravochnik.md` | каталог: семь привычек, все формулы с примерами «было → стало», ошибки содержания (обобщение шире данных, сумма не сходится), ошибки самой правки, какие советы ИИ-рецензентов не принимать |
| `scripts/schet.py` | счёт формул на 10 тысяч слов, сравнение с эталоном автора, список мест с номерами строк; цитаты «…» не считаются |
| `scripts/primenit.py` | внесение правок из JSONL: каждая цитата должна найтись ровно один раз, иначе не меняется ни один файл; копии файлов до правки |

Скрипты работают на Python 3.8+ без сторонних библиотек.

## Установка

**Claude Code:**

```bash
git clone https://github.com/abdublinn/formuly-ii-skill ~/.claude/skills/formuly-ii
```

**Codex:**

```bash
git clone https://github.com/abdublinn/formuly-ii-skill ~/.codex/skills/formuly-ii
```

Можно и без git: скачать архив и положить папку с `SKILL.md` в каталог скилов под именем `formuly-ii`. В тексте скила путь к скриптам записан как `<SKILL_DIR>/scripts/…`, агент подставит свою папку.

## Как пользоваться

Попросите агента обычными словами:

> Вычисти из главы 3 формулы ИИ, чтобы звучало как я сам. Мои посты до 2023 года лежат в папке `posts/`.

> Текст звучит как нейросеть, убери ИИ-след. Факты не меняй.

Агент посчитает формулы, разберёт каждое место, внесёт правки и покажет «было → стало» и вопросы, на которые нужен ваш ответ (например, какое число стоит за «почти никто», если в данных его нет).

Скрипты можно запускать и самому:

```bash
python scripts/schet.py глава.md --etalon posts/ --do-goda 2023 --mesta места.md
```

```bash
python scripts/primenit.py правки.jsonl --otchet было-стало.md
```

```bash
python scripts/primenit.py правки.jsonl --write
```

**Эталон** — ваши тексты, написанные до ИИ: посты, статьи, письма, лучше от 30 тысяч слов. `--do-goda 2023` берёт только файлы, у которых в начале стоит `date:` раньше 2023 года. Без эталона скрипт сравнит текст со встроенным ориентиром: частотами по постам одного автора нон-фикшн. Это грубая мерка, свой эталон точнее.

## Ограничения

- Только русский язык.
- Поиск по шаблонам находит кандидатов, решение по каждому месту принимается по контексту: часть совпадений законна (два самостоятельных факта через «а», цитаты, термины).
- Скил правит формулы и швы. Структуру текста, факты и выводы он не переписывает: такие вопросы уходят автору.
